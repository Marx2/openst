# openst Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a FastAPI service that wraps openbb to expose dividend yield and dividend history endpoints, with Redis-backed 24h cache, packaged as a Docker image.

**Architecture:** Minimal explicit-cache pattern (no decorators, no config.yaml). `openbb_client.py` contains pure openbb functions with yfinance→fmp fallback. `cache.py` is a thin sync Redis wrapper. `main.py` wires them together with explicit get/set per endpoint.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, openbb, redis (sync), python-dotenv, pytest, Docker multi-stage build.

import redis


class RedisCache:
    def __init__(self, host: str, port: int, password: str | None, db: int):
        self._client = redis.Redis(
            host=host,
            port=port,
            password=password or None,
            db=db,
            decode_responses=True,
        )

    def get(self, key: str) -> str | None:
        return self._client.get(key)

    def set(self, key: str, value: str, ttl: int = 86400) -> None:
        self._client.setex(key, ttl, value)
```

from decimal import Decimal
from dotenv import load_dotenv

load_dotenv()

from openbb import obb  # noqa: E402 — must load dotenv first


def get_dividend_yield(ticker: str) -> str | None:
    for provider in ["yfinance", "fmp"]:
        try:
            df = obb.equity.fundamental.metrics(ticker, provider=provider).to_df()
            if df.empty:
                continue
            raw = df.iloc[0]["dividend_yield"]
            return str(Decimal(str(raw)).quantize(Decimal("0.01")))
        except Exception:
            continue
    return None


def get_dividend_history(ticker: str) -> list[dict] | None:
    for provider in ["yfinance", "fmp"]:
        try:
            df = obb.equity.fundamental.dividends(ticker, provider=provider).to_df()
            if df.empty:
                continue
            rows = []
            for idx, row in df.iterrows():
                date = idx.date() if hasattr(idx, "date") else idx
                amount = str(Decimal(str(row["amount"])).quantize(Decimal("0.0001")))
                rows.append({"date": str(date), "amount": amount})
            return rows
        except Exception:
            continue
    return None
```

> **Note:** The exact column name for dividend amount (`"amount"`) and index name (`ex_dividend_date`) must be verified against real openbb output on first run. If columns differ, update the `row["amount"]` reference accordingly.

import json
import os

from dotenv import load_dotenv

load_dotenv()

from fastapi import FastAPI, HTTPException

from cache import RedisCache
from openbb_client import get_dividend_history, get_dividend_yield

app = FastAPI()

_cache = RedisCache(
    host=os.environ.get("REDIS_HOST", "localhost"),
    port=int(os.environ.get("REDIS_PORT", 6379)),
    password=os.environ.get("REDIS_PASSWORD") or None,
    db=int(os.environ.get("REDIS_DB", 0)),
)


@app.get("/dividend/yield/{ticker}")
def dividend_yield(ticker: str):
    key = f"dividend_yield:{ticker}"
    cached = _cache.get(key)
    if cached is not None:
        return json.loads(cached)

    value = get_dividend_yield(ticker)
    if value is None:
        raise HTTPException(status_code=404, detail=f"No dividend yield data for {ticker}")

    _cache.set(key, json.dumps(value))
    return value


@app.get("/dividend/history/{ticker}")
def dividend_history(ticker: str):
    key = f"dividend_history:{ticker}"
    cached = _cache.get(key)
    if cached is not None:
        return json.loads(cached)

    value = get_dividend_history(ticker)
    if value is None:
        raise HTTPException(status_code=404, detail=f"No dividend history data for {ticker}")

    _cache.set(key, json.dumps(value))
    return value
```

# openst

OpenBB wrapper service. Exposes financial data via HTTP with 24h Redis cache.

## Endpoints

| Method | Path | Returns |
|--------|------|---------|
| GET | `/dividend/yield/{ticker}` | Current dividend yield as decimal string, e.g. `"2.45"` |
| GET | `/dividend/history/{ticker}` | Dividend payment history, e.g. `[{"date": "2024-03-15", "amount": "0.2500"}]` |

Returns `404` if no data found, `502` if all providers fail.

## Run

```bash
cp .env.example .env   # fill in OPENBB_PAT
docker compose up --build
```

Service available at `http://localhost:8080`.

## Test

```bash
docker compose --profile test run --rm test
```

## Environment Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `OPENBB_PAT` | Yes | — | OpenBB personal access token |
| `REDIS_HOST` | No | `localhost` | Redis hostname |
| `REDIS_PORT` | No | `6379` | Redis port |
| `REDIS_PASSWORD` | No | `` | Redis password |
| `REDIS_DB` | No | `0` | Redis database index |
```
